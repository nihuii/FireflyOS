# FireflyOS 存储、音频与媒体应用 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立可靠的 NVS/内部文件系统/SD 分层存储，接入 ES8311 与 I2S，并交付可独立运行的主题、文件、音乐和录音能力。

**Architecture:** StorageService 是所有文件与配置访问入口；SD 缺失时系统正常降级。AudioService 独占 Codec/I2S 会话，音乐、录音和铃声通过明确优先级串行使用音频硬件，避免首版混音复杂度。

**Tech Stack:** Preferences/NVS、LittleFS、SD_MMC、ES8311、ESP_I2S、WAV/PCM、LVGL 8.3.11。

## 5. Task 4：接入 ES8311 与 AudioService

**Files:**
- Create: `libraries/FireflyOS/src/firefly/hal/Es8311Device.*`
- Create: `libraries/FireflyOS/src/firefly/services/AudioService.*`
- Modify: `tests/FireflyCoreTests/FireflyCoreTests.ino`

- [ ] **Step 1: 建立最小音频探测草图**

  以 `examples/08_ES8311/08_ES8311.ino` 为硬件基线，使用 I2S pins `41,45,40,42,16`、功放使能 pin `46`、16kHz/16-bit。先播放内置短 PCM，再录入 2 秒并回放。

- [ ] **Step 2: 定义会话优先级测试**

  ```cpp
  static void test_audio_session_priority() {
      firefly::AudioSessionArbiter arbiter;
      expect_true(arbiter.acquire(firefly::AudioUse::Music), "music acquires");
      expect_true(arbiter.acquire(firefly::AudioUse::Alarm), "alarm preempts music");
      expect_true(arbiter.current() == firefly::AudioUse::Alarm, "alarm owns audio");
      expect_true(!arbiter.acquire(firefly::AudioUse::Recorder),
                  "recorder cannot interrupt alarm");
  }
  ```

- [ ] **Step 3: 定义 AudioService 接口**

  ```cpp
  enum class AudioUse : uint8_t { None, System, Music, Recorder, Alarm };

  class AudioSessionArbiter {
  public:
      bool acquire(AudioUse requested);
      void release(AudioUse owner);
      AudioUse current() const { return current_; }
  private:
      AudioUse current_ = AudioUse::None;
  };

  class AudioService {
  public:
      bool begin();
      bool playPcm(const int16_t * samples, size_t frames, uint32_t sample_rate,
                   AudioUse use);
      bool playWav(const char * path, AudioUse use);
      bool startRecording(const char * path, uint32_t sample_rate = 16000);
      void stop();
      void setVolume(uint8_t percent);
      AudioUse activeUse() const;
  };
  ```

- [ ] **Step 4: 实现互斥会话**

  AudioSessionArbiter 使用显式优先级函数实现 Alarm > Recorder > System > Music。Alarm 可暂停音乐；录音与播放互斥；停止后关闭功放并让 Codec 进入低功耗。音频回调不得调用 LVGL。

- [ ] **Step 5: 实现 WAV 最小格式**

  首版支持 PCM WAV：单声道/双声道、16-bit、8–48kHz。录音固定为单声道 16kHz/16-bit；开始时预写 WAV 头，停止时回填数据长度，断电恢复时丢弃无法校验的临时文件。

- [ ] **Step 6: 运行 30 分钟循环测试并提交**

  音乐播放、暂停、闹钟抢占、录音各循环 20 次。Expected: 无 I2S 初始化失败、无持续堆下降、停止后功放关闭。
