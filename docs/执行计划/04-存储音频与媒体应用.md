# 计划 4：存储、音频与媒体应用

## 1. 目标与当前状态

当前 main 有 Preferences/NVS 使用、32MB 分区中的 FFat、SD 与 ES8311 板级示例、闹钟 UI，以及 Music、Recorder、Files 的路由占位；没有统一 StorageService、受管 SD 入口、AudioService 或完整媒体应用。本计划从存储所有权开始，逐层建立主题、音频、文件、音乐和录音闭环。

## 2. 知识库依据

- [05-存储、文件与 SD 卡](../../knowledge/05-存储文件与SD卡.md)
- [06-音频、音乐与录音](../../knowledge/06-音频音乐与录音.md)
- [07-主题包与资源管理](../../knowledge/07-主题包与资源管理.md)

卡片 05 和 06 的唯一主要计划是计划 4；卡片 07 主要归计划 2，本计划只接入其受控外部资源流程。

## 3. 前置条件与禁止事项

- 计划 3 的共享 I²C、电源门控和真机稳定点已建立。
- 配置使用 NVS；当前内部文件区使用分区表对应的 FFat，不假设其他内部文件系统。
- SD 只开放 `/FireflyOS` 白名单目录；禁止格式化整卡或递归操作根目录。
- UI 不同步扫描大目录、不解码整文件、不直接持有底层文件句柄。
- 音频、SD、Bulk 和 OTA 必须使用显式租约；无会话时关闭高功耗硬件。

## 4. 功能范围与明确非目标

范围包括配置 schema、FFat 缓存、SD 受管目录/句柄/分页扫描、主题包验证与回滚、ES8311/I²S、WAV/PCM、铃声、Files/Music/Recorder/Themes 应用。非目标包括通用文件管理器、压缩格式大全、后台静默录音、云媒体和网络传输。

## 5. 分任务实施顺序

### Task 1：建立版本化 NVS 与 FFat 边界

- [ ] **文件范围：** 现有 Preferences 调用、`Firefly/partitions.csv`、计划创建的存储 schema/服务及测试。
- [ ] **预期失败：** 旧 schema、迁移中断、FFat 不可用和配置损坏测试先失败；启动不得自动格式化。
- [ ] **最小实现：** NVS 保存小型设置，FFat 保存有界缓存/轻日志；版本迁移失败进入只读恢复。
- [ ] **验证命令：** 运行配置迁移与分区契约测试，随后构建主固件。
- [ ] **预期结果：** 配置所有权明确，分区偏移不改变，失败不会清空用户数据。

### Task 2：建立受管 SD、句柄和分页扫描

- [ ] **文件范围：** `examples/07_LVGL_SD_Test/`、计划创建的 `SdCardDevice.*`、`StorageService.*`、`FileScanService.*` 和测试。
- [ ] **预期失败：** `..`、盘符、反斜杠、超长路径、拔卡、句柄泄漏和租约冲突测试先失败。
- [ ] **最小实现：** 白名单路径、自动关闭句柄、固定页扫描、generation 丢弃过期结果和 Bulk/OTA 独占租约。
- [ ] **验证命令：** 运行路径/租约测试、主固件构建和 SD 探针。
- [ ] **预期结果：** UI tick 内无大目录长阻塞，拔卡后句柄关闭并发布明确状态。

### Task 3：接入外部主题包

- [ ] **文件范围：** 当前 `UiTheme.*`/`UiTokens.h`、计划创建的主题包服务、Themes 页面、预览与测试。
- [ ] **预期失败：** 非法路径、超预算、缺资源、半激活和掉电恢复测试先失败。
- [ ] **最小实现：** 全量验证后原子激活，失败恢复旧缓存/设置；默认中性主题始终可用。
- [ ] **验证命令：** 运行清单/路径/预算测试、410×502 预览和连续切换构建检查。
- [ ] **预期结果：** 外部主题不携带执行代码，不改变服务边界；受保护提示词目录不受影响。

### Task 4：建立音频仲裁与板级探针

- [ ] **文件范围：** `examples/08_ES8311/`、计划创建的音频 HAL/服务、资源治理和测试。
- [ ] **预期失败：** `Alarm > Recorder > System > Music` 仲裁、抢占清理、低电拒绝和设备失败测试先失败。
- [ ] **最小实现：** UI 只申请会话；Codec、I²S、功放和固定 PCM 块由单一服务管理，先完成独立探针。
- [ ] **验证命令：** 运行纯内存仲裁测试、AudioProbe 构建与当前板播放/录音探针。
- [ ] **预期结果：** 软件仲裁确定，真机能听到提示音并录得可解析样本；缺硬件证据时保持待真机。

### Task 5：接入铃声、WAV 播放与录音收尾

- [ ] **文件范围：** `Firefly/FireflyAlarm.*`、AudioService、WAV 解析/写入、受管存储和测试。
- [ ] **预期失败：** 坏头、短读、拔卡、抢占、低电停止、WAV 头回填失败和重启恢复测试先失败。
- [ ] **最小实现：** 固定块播放；录音写 `.tmp`，停止时回填头、关闭并原子改名，失败保留可恢复临时文件。
- [ ] **验证命令：** 运行 WAV/清理测试、主固件构建和 30 分钟循环真机测试。
- [ ] **预期结果：** 闹钟音频失败仍有全屏警报，所有退出路径归还音频与 SD 租约。

### Task 6：实现 Files、Music、Recorder 与 Themes 页面闭环

- [ ] **文件范围：** 计划创建的应用目录、AppRegistry、系统预览和 UI 测试。
- [ ] **预期失败：** 先用预览/契约捕获空数据、无 SD、播放冲突、录音可见性、分页和退出回收问题。
- [ ] **最小实现：** 每次只把一个占位路由替换为快照驱动页面，退出释放非必要对象和资源。
- [ ] **验证命令：** 运行 UI 预览、应用契约、主固件构建与每个应用独立真机清单。
- [ ] **预期结果：** 页面不直接访问芯片或裸文件句柄；未完成的应用继续标记部分已有。

## 6. 自动验证

运行 `python knowledge/validate_knowledge.py`、存储/音频/主题单元测试、`python -m unittest discover -s tests/python -v` 和完整主固件构建。预期路径、容量、租约、抢占和清理失败都有确定断言。

## 7. 真机验收

- [ ] NVS 迁移、FFat 不可用与断电恢复不清空配置。
- [ ] 多容量 SD 卡挂载、分页扫描、写入、热拔插和重新插入可恢复。
- [ ] 主题连续切换 20 次，裁切、颜色、内存峰值和失败回滚正确。
- [ ] 铃声、WAV 播放、录音、拔卡、低电和抢占路径分别验证。
- [ ] 音频与 UI 并发 30 分钟无看门狗复位、跨线程 LVGL 或资源泄漏。

## 8. 退出门槛与下一计划

存储与音频的每个资源退出路径、媒体应用真机闭环和功耗记录完成后，计划 4 才能退出并进入计划 5。路由可见或示例探针通过不足以升级为完整应用。
