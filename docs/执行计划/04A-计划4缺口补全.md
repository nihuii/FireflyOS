# FireflyOS 计划 4 缺口补全 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 补齐计划 4 审计确认的存储入口、SD 失败传播、闹钟事件链、文件后台分页、主题资源诊断和完整动态换肤缺口。

**Architecture:** StorageService 成为受管 SD 文件会话入口并把操作结果交给 SdCardDevice；AlarmService 只发布有界系统事件，UI 主循环消费后操作 LVGL；文件扫描由不访问 LVGL 的固定容量 worker 推进并发布页结果事件；主题清单携带 RGB565 宽高，校验返回具体资源诊断，运行时颜色通过递归令牌映射应用到现有控件树。

**Tech Stack:** Arduino ESP32、FreeRTOS、SD_MMC、LVGL 8.3.11、Python unittest、Arduino CLI。
