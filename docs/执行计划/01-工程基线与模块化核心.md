# FireflyOS 工程基线与模块化核心 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不改变现有 UI 行为的前提下，建立可复现构建、测试入口和 FireflyOS 模块化核心，为后续服务与应用迁移提供稳定边界。

> **执行状态（2026-07-01）：** Tasks 1–10 的软件实现、自动测试和编译验证已完成。Gate A 的真机页面回归、连续按键/息屏压力测试、运行时 SRAM 余量与锁屏进入桌面耗时仍待采集，因此 Gate A 尚未关闭。详见 `docs/模块说明/00-当前基线.md`。

**Architecture:** 新建本地 Arduino 库 `libraries/FireflyOS`，先承载不依赖 LVGL 的 EventBus、StateStore、CapabilityRegistry 和 AppRegistry。现有草图继续运行，后台事件逐步改为投递 `SystemEvent`，UI 仍在原主循环消费。

**Tech Stack:** Arduino-ESP32、C++17 可用子集、FreeRTOS 临界区、Python 3 unittest、PowerShell、LVGL 8.3.11。

- [ ] **Step 4: 实现固定容量队列**

  `EventBus.h`：

  ```cpp
  #pragma once
  #include "SystemEvent.h"

  namespace firefly {

  class EventBus {
  public:
      static constexpr uint8_t kCapacity = 16;
      bool post(const SystemEvent & event);
      bool take(SystemEvent & event);
      uint8_t size() const;

  private:
      SystemEvent events_[kCapacity]{};
      uint8_t head_ = 0;
      uint8_t tail_ = 0;
      uint8_t count_ = 0;
  };

  }  // namespace firefly
  ```

  同时在 `FireflyOS.h` 加入：

  ```cpp
  #include "firefly/core/SystemEvent.h"
  #include "firefly/core/EventBus.h"
  ```

  `EventBus.cpp`：

  ```cpp
  #include "EventBus.h"

  namespace firefly {

  bool EventBus::post(const SystemEvent & event) {
      if(count_ == kCapacity) {
          if(event.priority != EventPriority::Critical) return false;
          uint8_t index = head_;
          bool found_refresh = false;
          for(uint8_t i = 0; i < count_; ++i) {
              if(events_[index].priority == EventPriority::Refresh) {
                  found_refresh = true;
                  break;
              }
              index = static_cast<uint8_t>((index + 1U) % kCapacity);
          }
          if(!found_refresh) return false;
          events_[index] = event;
          return true;
      }
      events_[tail_] = event;
      tail_ = static_cast<uint8_t>((tail_ + 1U) % kCapacity);
      ++count_;
      return true;
  }

  bool EventBus::take(SystemEvent & event) {
      if(count_ == 0) return false;
      event = events_[head_];
      head_ = static_cast<uint8_t>((head_ + 1U) % kCapacity);
      --count_;
      return true;
  }

  uint8_t EventBus::size() const {
      return count_;
  }

  }  // namespace firefly
  ```

  ```cpp
      const AppDescriptor * find(const char * id) const;
      uint8_t count() const { return count_; }
      const AppDescriptor & at(uint8_t index) const { return apps_[index]; }
  private:
      AppDescriptor apps_[kMaxApps]{};
      uint8_t count_ = 0;
  };
  }
  ```

  提供 `constexpr uint16_t capabilityBit(Capability value)`；应用可组合 `Audio | Sd` 等多项要求。`add()` 拒绝空 id、重复 id 和超过 16 个应用；`find()` 使用 `strcmp` 精确匹配。
