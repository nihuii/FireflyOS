# FireflyOS 总体执行路线图

## 1. 基线与权威顺序

唯一开发基线是 `main@fab5509`。执行前先读取 [当前交接](../项目介绍-对话衔接版.md)、[系统架构总纲](../FireflyOS系统架构总纲.md)、[知识库索引](../../knowledge/README.md)和[渐进集成顺序](../../knowledge/14-主程序集成与后续复用顺序.md)。

发生冲突时依次采用：当前工作区源码与实时 Git 证据、当前交接、知识库模块卡片、执行计划、本地历史对象。执行计划只定义后续工作，不能反向证明功能已经存在；本地历史对象只允许人工提炼少量思路。

当前工作区包含用户未提交的删除和知识库改写。实施任何功能前必须记录完整状态，保留既有变更；未经最终 diff 审查，不恢复、选择性暂存或提交。Arduino 配置指南只用于当前板卡、构建和 Sketchbook 设置。

## 2. 统一状态模型

| 状态 | 判定标准 |
|---|---|
| 当前已有 | 当前工作区存在可调用实现；仍可能有缺陷或缺少真机验收 |
| 部分已有 | 只有主程序装配、基础适配、UI 路由、能力枚举或配置基础 |
| 待开发 | 当前树中没有目标服务或完整业务闭环 |
| 待真机 | 软件证据存在，但硬件、稳定性、功耗或互操作未在当前基线重新验证 |
| 阻塞 | 缺少必要硬件证据、外部生产材料或用户授权，不能安全推进 |

UI 占位、枚举、分区布局、历史对象、编译通过和自动测试均不能单独升级为“当前已有完整能力”或“真机通过”。

## 4. 计划职责与执行顺序

1. 计划 1/1A 保留当前核心原语，补足诊断、资源边界和 Gate A 设备证据；不提前实现 OTA。
2. 计划 2/2A 先真机验证系统面板上滑修复，再稳定锁屏、桌面、BOOT、一瞥与息屏基线。
3. 计划 3 先把 Touch 纳入共享 I²C 所有权，再逐步收敛时间、闹钟、电源和 IMU 服务。
4. 计划 4 先建立 NVS、FFat、SD 受管入口，再加入主题、音频和媒体应用。
5. 计划 5 从 BLE Hello、Pair、Ack 和安全会话开始，随后创建 Android 伴侣并逐项同步业务。
6. 计划 6 依次完成 NTP、配网、天气、传输、签名 OTA、首启回滚、恢复出厂和 Release 闭锁。

阶段失败时回到最近的真机稳定点。不得通过扩大后续范围来掩盖较早责任模块的问题。

## 5. 统一实施循环

- [ ] 在改动前记录 `git status --short --branch`、相关 diff 和当前自动/真机证据。
- [ ] 为行为变更先增加能按预期失败的测试或可复现检查。
- [ ] 只实现当前任务的最小闭环；队列、缓存、导航和输入均保持固定容量。
- [ ] 涉及 UI 时先完成 410×502 预览；LVGL 仅由 UI 主循环访问。
- [ ] 涉及硬件、存储、音频或无线时分别保存自动证据与真机证据。
- [ ] 完成后运行知识库校验、相关测试、构建和 `git diff --check`。
- [ ] 最终审查完整 diff；Git 交付动作必须另获用户明确授权。

## 6. 统一验收原则

| 门槛 | 自动证据 | 真机证据 | 退出条件 |
|---|---|---|---|
| Gate A | 核心测试、仓库契约、构建配置 | 启动日志、队列/内存水位、故障可观测性 | 核心边界可用且未把 OTA 作为前置 |
| Gate B | UI 合约、预览、导航与层级测试 | 触摸、圆角、连续手势、BOOT/息屏和转场 | 面板上滑稳定，硬件基线可区分设计行为与崩溃 |
| Gate C | 时间、电源、IMU、存储、音频状态测试 | I²C 并发、RTC、功耗、SD、音频和长稳 | 独立设备能力形成真实闭环 |
| Gate D | 双端黄金帧、协议、安全和 Android 单测 | 配对、重连、权限、通知和多手机互操作 | 断开手机不破坏本地能力 |
| Gate E | 网络、传输、清单、签名、分区与发布检查 | 弱网、断电、回滚、恢复、24h 长稳和续航 | 缺生产材料时明确阻塞，不生成候选发布物 |

未执行的真机项保持“待真机”，不能沿用旧 Gate 结论。

## 8. 全局禁止事项

- 不在后台任务、无线回调、存储回调或硬件中断中访问 LVGL。
- Touch 未进入共享 I²C 所有权前，不启用后台 RTC、PMU、IMU 并发轮询。
- 不把 Android、BLE、Wi-Fi、存储媒体、传输或 OTA 写成当前完整实现。
- 不恢复已删除项目介绍，不触碰 `image/图片生成提示词`。
- 不记录生产密钥、私有端点、Wi-Fi 密码或用户凭据。
- 未经明确授权不删除、恢复、暂存、提交、合并、推送或创建标签。
