# 计划 2：UI Shell 与视觉系统

## 1. 目标与当前状态

当前 main 已有四层 UiShell、固定深度导航、主题令牌、通用组件、锁屏、桌面、控制中心、通知中心和覆盖层；这些属于“当前已有、待真机”。Activity、Weather、Music、Recorder、Files 等入口仍使用统一占位页。系统面板内部子命中目标截断问题已经加入完整冒泡与方向仲裁的软件修复，当前首要缺口是目标板手势矩阵和 BOOT/息屏基线。

本计划保留现有 Shell，收口层级、生命周期、资源和 Gate B；具体首要修复由计划 2A 执行。

## 2. 知识库依据

- [02-UI Shell 与导航覆盖层](../../knowledge/02-UI-Shell与导航覆盖层.md)
- [07-主题包与资源管理](../../knowledge/07-主题包与资源管理.md)

卡片 02 和 07 的唯一主要计划是计划 2；外部主题包的存储接入在计划 4 作为交叉实现。

## 3. 前置条件与禁止事项

- LVGL 对象、动画、样式和页面生命周期只由 UI 主循环访问。
- 任何正式视觉变化先更新 410×502 预览并获得确认；本次纯事件传播修复不得顺带改视觉。
- 不改变四层 Z 顺序，不扩大导航、通知、覆盖层或资源缓存容量。
- 不把无线快捷项、应用路由或图标占位写成真实服务。
- 不触碰受保护图片提示词，也不执行 Git 交付动作。

## 4. 功能范围与明确非目标

范围包括 Shell 层级、路由/返回、页面 create/show/hide/refresh 生命周期、系统面板、覆盖层优先级、主题令牌、字体/图标流水线、预览和 Gate B。非目标包括实现 Activity/Weather/Music/Recorder/Files 业务、后台设备服务、共享 I²C、无线和 OTA。

## 5. 分任务实施顺序

### Task 1：锁定 Shell、导航和页面生命周期

- [ ] **文件范围：** `libraries/FireflyOS/src/firefly/ui/`、`Firefly/Firefly.ino`、UI 合约测试。
- [ ] **预期失败：** 先增加层级、导航上限、锁屏清栈和隐藏页面停止刷新等契约；缺失时测试应准确失败。
- [ ] **最小实现：** 保留 app/status/panel/overlay 四层，统一 route 回调和 Screen 生命周期，不创建新业务页面。
- [ ] **验证命令：** `python -m unittest tests.python.test_repository_contracts -v`，再构建主固件。
- [ ] **预期结果：** 导航固定容量，覆盖层永远高于系统面板，后台代码不含 LVGL 调用。

### Task 2：完成系统面板与覆盖层收口

- [ ] **文件范围：** `Firefly/FireflyInteraction.cpp`、`UiShell.*`、`ControlCenter.*`、`NotificationCenter.*`、`SystemOverlayHost.*`。
- [ ] **预期失败：** 先复现面板子控件区域上滑不返回、释放/取消未收尾或低优先级覆盖高优先级。
- [ ] **最小实现：** 按计划 2A 统一完整区域事件所有权；保持 180ms 单父容器位移动画和固定覆盖层槽位。
- [ ] **验证命令：** 运行 UI 合约、预览检查和主固件构建。
- [ ] **预期结果：** 控制/通知切换不破坏上滑返回，事件取消后状态复位，覆盖层优先级确定。

### Task 3：收口主题、组件和资源预算

- [ ] **文件范围：** `UiTokens.h`、`UiTheme.*`、`UiComponents.*`、字体工具、`docs/UI预览/01-Shell/`。
- [ ] **预期失败：** 预览或契约先捕获非 410×502 画布、缺安全区、触摸目标小于 48px、运行时重复采样或资源预算缺失。
- [ ] **最小实现：** 复用集中 token 和组件，保留默认主题；正式资源替换不改变对象尺寸和热区。
- [ ] **验证命令：** 运行仓库 UI 合约和现有预览检查，记录生成字体和资源体积。
- [ ] **预期结果：** 六个 Shell 预览状态、圆角安全区和固定资源预算可复核；真机色彩仍待设备确认。

## 7. 真机验收

- [ ] 锁屏上滑、桌面下拉、面板上滑、控制/通知切换分别连续 20 次。
- [ ] BOOT 在应用、设置子页、桌面和覆盖层状态下语义正确。
- [ ] 四角、底部按钮和主要 48px 触摸目标无裁切或误触。
- [ ] 设置开关 50 次、锁屏转场 20 次、息屏轮播 10 次后对象与内存回到稳定区间。
- [ ] 高优先级覆盖层出现时阻止底层交互，关闭后恢复正确界面。
