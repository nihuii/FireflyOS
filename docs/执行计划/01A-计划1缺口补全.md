# FireflyOS 计划 1 缺口补全 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans and superpowers:test-driven-development. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 补齐 OTA 安全准入、共享 I2C 实际覆盖与 Gate A 诊断证据，并将验证后的功能分支合并到 `main`。

**Architecture:** 生命周期只决定状态路径，资源治理器决定 OTA 是否可进入；RTC、PMU 和寄存器设备统一经带超时的 I2C 管理器；UI 核继续是唯一 LVGL 调用方。

**Tech Stack:** Arduino-ESP32、FreeRTOS、TwoWire、LVGL 8.3.11、Python unittest、PowerShell。
