# 手表配对与解绑资源预算

## UI 与固定容量

- 屏幕基准为 410 × 502，四角保留 24px 安全区。
- 所有按钮有效触摸高度至少 48px；配对请求、成功、失败和解绑确认均为独立有限状态。
- 手机设备名按 UTF-8 截断并保存在固定 32 字节缓冲中；验证码固定为 6 位，不使用动态列表。
- 页面只使用 LVGL 基础图形、现有字体和字符占位图标，不新增常驻位图。

## 安全材料

- 每个绑定只保存一份随机 128-bit app token，命名空间固定为 `ff_pair`。
- 敏感消息使用 HMAC-SHA256 并截断为 8 字节认证标签；验证缓冲固定容量。
- PIN、app token、HMAC 密钥和 Wi-Fi 密码不记录到串口、诊断日志或错误事件。
- 连续认证失败计数使用单字节饱和计数器，达到 5 次立即断开。

## 生命周期

- 配对浮层只由 LVGL UI 主循环创建、更新和销毁；BLE 回调只投递固定容量事件。
- 失败、拒绝、超时或断连都会清除临时验证码和未提交 token。
- 解绑清除 bonding、token、通知缓存和手机名；不遍历或删除闹钟、媒体与活动存储。
