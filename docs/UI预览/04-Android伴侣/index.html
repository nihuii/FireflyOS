离线状态 远程操作已禁用

  • 离线可浏览最近设备信息，包括设备名、电量、上次同步时间、主题和最近天气摘要。
  • 设置写入、天气刷新、媒体控制、找手机、固件更新和解除绑定等远程操作显示禁用态，并说明“等待 BLE 连接后可用”。
  • 页面文案明确：手机伴侣是增强能力；手表本地时间、闹钟、媒体和活动继续独立运行。
  • 所有危险或远程按钮保持至少 48px 高度；禁用按钮同时设置 `disabled` 与 `aria-disabled="true"`。

权限边界 最小化

  • BLE 扫描只用于用户明确发起的配对流程，不申请后台位置。
  • Android 12+ 使用 Nearby Devices；旧系统兼容权限限制到 maxSdkVersion=30。
  • READ_CALENDAR 仅在用户主动启用“同步日程摘要”时请求，拒绝后通知、设置、媒体和找设备仍可使用。
  • 通知授权页面解释同步字段上限，避免让用户误以为会上传完整通知历史。
