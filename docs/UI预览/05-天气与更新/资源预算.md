# Wi-Fi 配网与天气预览资源预算

## 固定边界

- 手表画布固定为 410 × 502，基础安全区为四边 24px，底部主要按钮进一步内缩。
- 手表所有主要触摸目标至少 48 × 48px；Android 关键按钮至少 48dp。
- 配网和天气页面只能由 LVGL UI 主循环创建、更新和销毁；BLE、Wi-Fi、HTTP、JSON、NVS 和 LittleFS 工作只投递固定容量状态或事件。
- 当前预览不引入角色立绘、壁纸或正式图标，也不修改 `image\图片生成提示词`。

## 动效与功耗

- 仅“正在更新”状态允许单个 96px 局部旋转/透明度动效；页面隐藏、低电量或省电模式立即停止。
- Wi-Fi 默认关闭；普通天气会话空闲 60 秒关闭，连接阶段最多 15 秒。
- 预览不能证明真机触摸、安全区、AMOLED 偏色、RAM、功耗或联网成功；这些项目保持 `PENDING`。
