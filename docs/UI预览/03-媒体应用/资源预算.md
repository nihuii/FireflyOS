# 媒体应用资源预算

## 固定容量

- FilesApp 每页最多 32 项，每项名称固定 48 字节，不递归扫描全盘。
- MusicApp 最多索引 128 首 WAV，只保存路径、标题、时长和状态。
- RecorderApp 使用一块至多 512 字节的 I2S 服务缓冲；录音文件流式写入 SD。
- ThemesApp 同时只保留一个预览资源，离开页面立即释放。

## 美术与主题约束

- 屏幕基准为 410 × 502；壁纸不得超过该尺寸。
- 单个图标包不得超过 512KB。
- 正式图标、封面和角色美术当前均使用占位资源，不进入固件常驻大图预算。
- 页面沿用现有系统字体；不因媒体应用新增完整中文字库。

## 运行时约束

- 所有按钮和列表行的有效触摸高度至少 48px。
- 音乐/录音会话不访问 LVGL；UI 主循环只读取状态并刷新控件。
- SD 缺失、Codec 不可用和主题校验失败均局部降级，不阻塞核心应用。
- 录音和音乐页面正常状态按 4Hz 或更低更新；省电模式降为 1Hz。
