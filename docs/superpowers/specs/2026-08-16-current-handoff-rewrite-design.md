## 目标

把旧的多工作树、计划 1～6 总装衔接文档重写为当前主分支的精简启动说明。新文档只保存下一次开发对话必须知道的事实，并把历史模块设计统一路由到 `knowledge/`，减少重复内容和上下文消耗。

## 内容结构

1. 项目定位、目标硬件和开发环境。
2. 当前 Git 基线、远端状态和目录结构。
3. 已进入当前 main 的核心运行时与 UI Shell 能力。
4. 当前不存在的 Android、BLE、存储媒体、Wi-Fi、传输和 OTA 服务说明。
5. LVGL、圆角安全区、触摸尺寸、固定容量、I²C 所有权和离线优先约束。
6. 当前未提交知识库重写、用户删除项和新增设计/计划文件。
7. 系统面板手势、BOOT/息屏、共享 I²C 和烧录链路等已知风险。
8. 先稳定 UI 与硬件基线、再逐模块恢复的开发顺序。
9. 新对话必读文件和可直接复制的启动提示。
