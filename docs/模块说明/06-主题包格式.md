# FireflyOS 主题包格式

主题包放在 `/FireflyOS/Themes/<主题 id>/`。首版采用固定容量解析，不在运行时构建动态 JSON 对象；清单上限为 2 KB。导入顺序是清单校验、资源校验、写入主题缓存、最后更新当前主题 id，因此失败时不会切走原主题。

## 清单示例

```json
{
  "schema": 1,
  "id": "firefly-accent",
  "name": "流萤",
  "author": "FireflyOS",
  "palette": {
    "bg_base": "#05090C",
    "bg_surface": "#0C1820",
    "primary": "#5FE7C7",
    "secondary": "#6EC4D6",
    "critical": "#FF5A5F"
  },
  "wallpaper": "wallpaper.rgb565",
  "wallpaper_width": 410,
  "wallpaper_height": 502,
  "glance": "glance.png",
  "icon_pack": "icons"
}
```

## 约束

- `schema` 当前只能为 `1`；`id` 为 1–23 个小写字母、数字或连字符。
- 五个色值必须全部存在，并使用 `#RRGGBB`。
- 资源路径必须相对主题目录，禁止绝对路径、`..`、反斜杠、空路径段和盘符。
- 壁纸只接受 `.rgb565`，清单必须声明 `wallpaper_width` 和 `wallpaper_height`；两边分别不得超过 410 和 502，文件字节数必须精确等于 `width × height × 2`。一瞥图只接受 `.png`，PNG 尺寸不得超过 410 × 502，文件不得超过 512 KB。
- 校验失败会返回具体资源名、实际值和限制值；任何失败都保留原主题 id，并恢复导入前的主题缓存。
- 图标包是目录，首版最多 64 个 `.png` 或 `.rgb565` 文件，总计不超过 512 KB，不递归扫描子目录。
- 固件总是提供中性基础主题 `system-default`（显示名 `Default`）。旧设置中的 `firefly-default` 会一次性迁移到 `system-default`，迁移不清除已有 palette 缓存。
- 流萤外观使用可替换标识 `firefly-accent`；可通过 `FIREFLYOS_INCLUDE_FIREFLY_THEME=0` 从公开构建中移除，之后由 SD 卡主题包安装。

主题图像仍是占位/用户资源；本任务不引入正式角色美术。
