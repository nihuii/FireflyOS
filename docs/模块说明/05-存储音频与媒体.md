# 存储、音频与媒体模块

## 1. 范围

计划 4 建立了版本化配置、内部文件系统、受管 SD 目录、ES8311/I2S 独占音频会话，以及 Files、Music、Recorder、Themes 四个本地应用。网络和手机互联不属于本阶段依赖，SD 或 Codec 缺失时核心系统继续运行。

## 2. 存储分层

- `StorageService` 管理 `ff_sys`、`ff_alarm`、`ff_pair`、`ff_stats` 四个版本化 NVS 命名空间，并负责旧 `firefly` Preferences 迁移。
- `StorageService` 也是受管 SD 会话的唯一业务入口；媒体应用、AudioService 和 ThemePackageService 不再保存裸 `fs::FS` 入口。
- SD open/read/write/seek/remove/rename 经带超时互斥边界串行化；客户端 I/O 结果回传 `SdCardDevice`，连续两次真实失败进入既有 `SdRemoved` 流程。
- LittleFS 只用于有界缓存与诊断数据；挂载失败不会自动格式化。
- `SdCardDevice` 使用 1-bit SD_MMC：CLK 2、CMD 1、DATA 3。
- SD 根目录固定为 `/FireflyOS/`，包含 Music、Recordings、Pictures、Themes、Updates、Backups、Logs 七个目录。
- 连续两次 SD 会话失败才发布 `SdRemoved`，避免一次瞬态错误引发错误拔卡状态。

## 3. 音频边界

- ES8311 地址为 `0x18`，寄存器通过共享 I2C 锁访问。
- I2S 引脚为 MCLK 41、BCLK 45、WS 40、DOUT 42、DIN 16，功放使能为 46。
- `AudioSessionArbiter` 优先级为 Alarm > Recorder > System > Music。
- 音频服务不调用 LVGL；UI 主循环调用 `service()` 或 `serviceRecording()` 推进固定缓冲流。
- 停止会话后功放拉低，Codec 进入低功耗。
- WAV 首版支持单/双声道、16-bit PCM 和 8–48kHz 已列出的采样率。

四个内置闹钟铃声保持稳定索引：Trailblaze、Starglow、Night Sky、Classic Bell。铃声为 16kHz 单声道短 PCM 循环资源；Codec 初始化失败时闹钟覆盖层仍出现，并显示 `Sound unavailable`。

闹钟到点链路为 `AlarmService::publishTrigger` → `EventBus::AlarmTriggered` → UI 主循环显示覆盖层并启动 Alarm 音频。事件发布失败不会提前消费本分钟触发，可在下一次时钟刷新重试。

## 4. 媒体应用

### Files

- 一次最多读取 32 项，文件名固定 48 字节。
- `FileScanService` 在后台任务推进扫描，每轮最多读取 4 项；完成后发布 `FilesPageReady`，FilesApp 只在 UI 主循环复制固定页邮箱并渲染 LVGL。
- 只展示七个受管目录，不接受任意路径输入。
- 只允许删除 Music、Recordings、Pictures、Themes 中的普通文件，长按后必须确认。

### Music

- 最多索引 128 首有效 WAV，不解析封面。
- 支持播放/暂停、上一首、下一首、进度和音量。
- 页面隐藏后音乐会话可继续；省电模式将界面状态刷新降为 1Hz。
- 闹钟抢占后音乐保持暂停，用户可恢复；拔卡时只丢弃音乐文件句柄，不误停闹钟。

### Recorder

- 开始前要求至少 2MB 可用空间。
- RTC 有效时使用 `REC_YYYYMMDD_HHMMSS.wav`；否则使用单调序号。
- 先写 `.tmp`，停止后回填 WAV 头并重命名为 `.wav`。
- 录音时状态栏和一瞥界面持续显示 `REC/RECORDING`，并阻止会停止 I2S 的黑屏轻睡眠。
- 拔卡、极低电量、温度保护或关机路径会停止录音；失败临时文件不进入正常列表，下次挂载时清理。

### Themes

- 最多列出 16 个通过清单和资源边界检查的主题。
- 清单必须声明 RGB565 壁纸宽高；宽、高分别不超过 410、502，文件大小必须精确等于 `width × height × 2`。PNG 预览尺寸不超过 410 × 502，图标包不超过 512KB。
- 校验错误携带具体资源名、实际值和限制值；设置写入失败会恢复导入前的主题缓存和主题 id。
- 应用前保存旧设置；导入失败时恢复旧主题 id，不重启系统。
- 预览状态离开页面立即释放。
- 应用成功后递归重映射现有控件树中的背景、文本、边框、轮廓、弧线、线条、阴影和图片重着色主题令牌，无需重启。

## 5. 资源与并发

- 所有列表和队列使用固定容量，不保存封面或全天原始音频到内存。
- UI 与 LVGL 仍只在 Arduino 主循环访问。
- Files 扫描在后台每轮处理 4 项并以事件交付固定页，不创建第二条 LVGL 执行链；其他媒体操作由 StorageService 互斥串行化。
- 音频流每次处理固定大小块，避免整首 WAV 载入内存。
- 正式图标、封面、壁纸和角色美术继续使用占位资源。
