## 串口采集格式

固件在 `setup()` 完成页面与后台任务初始化后输出一次：

```text
FIREFLY_BASELINE startup_ms=<ms> internal_free=<bytes> internal_min=<bytes> psram_free=<bytes> psram_size=<bytes>
```

将串口日志保存为 UTF-8 文本后，可使用：

```powershell
python .\tools\capture_baseline.py .\baseline-serial.log
```

脚本只解析真实串口数据，不会补写缺失指标。续航、交互耗时与页面回归仍需人工真机记录。

## 已知编译警告

- `libraries/lv_conf.h` 的既有注释格式触发 `-Wcomment`。
- `FireflyInteraction.cpp` 存在既有的结构体初始化、无效范围比较和日期格式化警告。
- TouchLib 与 XPowersLib 都定义了 `IS_BIT_SET`，产生宏重定义警告。

这些警告在模块化迁移前已经存在。本阶段只冻结基线，不混入行为修复；后续以独立任务处理。

基线日志加入前的固件大小为 2,225,585 字节；日志本身增加 1,472 字节，作为后续体积对比时应保留这一测量边界。
