# FireflyOS 发布清单

## 1. 使用规则

本清单用于候选版本前的逐项签字。当前阶段禁止创建 RC 标签；只有自动验证、生产材料审计和 Gate E 真机矩阵全部通过后，才允许由用户另行批准创建候选标签、提交、合并或推送。

## 2. 代码与架构

- [ ] LVGL 固定为 8.3.11，且只由 UI 主循环访问。
- [ ] 所有队列、清单、日志、传输窗口和页面缓存均有固定上限。
- [ ] 中性基础主题可独立编译；核心、协议和服务不引用角色素材路径。
- [ ] 410×502 圆角安全区和至少 48px 触摸区已逐页真机确认。
- [ ] Wi-Fi、BLE、SD、音频、更新与 LightSleep 的资源仲裁无冲突。

## 3. 构建与发布材料

- [ ] Python 契约全集通过并记录数量。
- [ ] FireflyCoreTests、AudioProbe、Firefly Development 编译通过并记录 Flash/RAM。
- [ ] Android 单元测试和 Debug APK 构建通过并记录数量、大小与 SHA-256。
- [ ] `FireflyUpdatePublicKey.local.h` 已由发布负责人提供并核对生产公钥。
- [ ] `FireflyUpdateConfig.local.h` 已固定生产 HTTPS 主机、路径、CA 和文件名。
- [ ] `FIREFLY_SIGNING_KEY` 指向离线私钥，私钥未进入仓库或日志。
- [ ] `-Configuration Release` 成功，产物低于 `9,227,468` 字节发布预算。
- [ ] 发布固件、清单、签名和摘要由两人复核。

## 4. 功能与恢复

- [ ] SD 与 HTTPS 更新均在真机完成签名、摘要、容量和升级序列检查。
- [ ] 下载/写入各断电点和首启失败回滚完成。
- [ ] 普通恢复不删除 SD 媒体。
- [ ] `Delete managed FireflyOS data` 仅清理七个受管目录并保留未知内容。
- [ ] Wi-Fi 密码、token、HMAC、通知正文和录音内容未进入日志。
- [ ] Android 权限与锁屏正文隐藏默认值已在目标系统版本复核。

## 5. Gate E 与发布动作

- [ ] 24 小时稳定性通过。
- [ ] 400mAh 续航通过并归档测量条件。
- [ ] Gate D 与 Gate E 全部真机项目有证据且不再是 `PENDING`。
- [ ] 已知限制、烧录、分区、配对、SD、OTA、恢复说明与实际代码一致。
- [ ] 用户已明确批准创建候选版本。

任一项目未勾选时，结论只能是“软件实现或自动验证进行中”，不得写成真机通过、Gate E 通过或正式发布。
