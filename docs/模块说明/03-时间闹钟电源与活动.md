# FireflyOS 时间、闹钟、电源与活动模块

## 1. 阶段范围

计划 3 将时间、闹钟、电源状态、按键、QMI8658 运动数据和四个核心应用迁入 `libraries/FireflyOS/` 的模块边界。实现仍遵守以下约束：

- LVGL 固定为 8.3.11，只有 Arduino UI 主循环调用 LVGL。
- 后台任务只读取按键/运动源、计算状态并向容量 16 的 `EventBus` 投递事件。
- 运行时容器均为固定容量；运动服务只保留最近 32 个样本，不保存全天原始数据。
- 手机、网络和云端不是这些功能的运行前提。
- 活动数据是本地估算，不是医疗数据。

## 2. 已实现的软件能力

### 2.1 时间与闹钟

- `TimeService` 通过 `ClockDevice` 访问 PCF85063，支持 RTC 无效状态、重载、手动设置和系统时间快照。
- `AlarmService` 固定提供 2 个闹钟槽位，计算下一次触发时间并阻止同一分钟重复触发。
- `ClockApp` 展示时间、日期、下一闹钟、双闹钟、倒计时和秒表；倒计时提供 1/5/10 分钟预设、开始/暂停/继续/复位和一次性到期提醒，秒表提供开始/暂停/复位。两者都脱离页面可见性计时。
- `SettingsApp` 使用容量 8 的命令队列把时间、RTC 重载、双闹钟、亮度、音量和自动息屏意图交回 UI 主循环消费；回调不直接访问 RTC、Preferences 或硬件。

### 2.2 日历与工具

- `CalendarApp` 使用固定 42 格月历模型，支持前后月切换；日程摘要缓存上限为 8 条。
- `CalculatorEngine` 的表达式上限为 24 字符，显示结果受固定字符数约束，不使用动态表达式树。
- 手电筒以 AMOLED 白屏实现，启动前检查电池和温度，单次最长 60 秒；关闭后通过容量 4 的命令队列恢复原亮度。

### 2.3 电源与按键

- `PowerService` 对 Active、IdleDim、Glance、ScreenOff、Charging、Saver、LowBattery、CriticalBattery 和 ThermalProtection 做确定性判定。
- BOOT 使用 30ms 去抖，短按在释放时产生；PWR 读取 AXP2101 的短按/长按锁存事件。
- BOOT、PWR 和后台唤醒事件最终都由 UI 主循环消费。后台任务不直接切页、改亮度或调用 LVGL。
- `PowerService` 已提供 LightSleep 睡前/平台进入/恢复的完整调用结果，失败路径也会恢复已准备资源。真实 `esp_light_sleep_start()` 只可由 UI 主循环调用，并同时受编译期唤醒引脚与 BOOT/PWR/RTC 100/100 软件门禁约束。
- 发布配置仍停留在亮度归零的 ScreenOff；当前门禁为 0/100，因此不会执行真实 LightSleep。原因及启用门槛见 [04-低功耗唤醒矩阵.md](04-低功耗唤醒矩阵.md)。

### 2.4 QMI8658、计步与抬腕

- `Qmi8658Device` 复用共享 I2C 互斥边界；正常模式使用 4G 加速度计和陀螺仪，低功耗接口关闭陀螺仪并降低加速度采样率。
- `MotionService` 使用 32 项环形缓冲，聚合当天步数和活动分钟。
- 计步器对加速度模长执行一阶低通，使用上下阈值和 250–1200ms 步间隔限制。
- 抬腕同时要求姿态变化、屏幕朝向和最小角速度，冷却时间为 3 秒；屏幕已亮、充电中或活动页打开时不重复触发。
- 后台检测到抬腕后只投递 `Wake` 事件，UI 主循环仅在息屏黑屏状态执行唤醒。
- ScreenOff 但 CPU 继续运行时保持正常陀螺仪配置，避免破坏抬腕判定；只有准备进入已验证的 LightSleep 时才切换 QMI8658 低功耗模式，恢复失败会撤销 Motion 能力。
- `MotionService` 使用固定整数统计有效样本、无效样本、当前步数和抬腕事件；`FIREFLY_GATE_A` 每 10 秒汇总一次，不输出高频原始样本。
- 当天聚合数据每 15 分钟检查一次并在进入息屏前保存到 Preferences；同一天重启可恢复，日期变化会清零。
- QMI8658 初始化失败时，活动页显示不可用状态，其余应用继续运行。

## 3. 活动应用显示边界

活动应用只显示：

- 今日步数
- 活动分钟
- 8000 步目标环
- 传感器状态和“本地估算、非医疗”说明

页面不显示心率、血氧、睡眠分数、卡路里结论或其他不存在的传感器数据。正式角色图标尚未加入，桌面入口继续使用 LVGL Symbol 占位。
