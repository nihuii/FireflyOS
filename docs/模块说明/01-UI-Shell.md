# FireflyOS UI Shell 模块说明

## 1. 模块目标

UI Shell 是 410 × 502 圆角 AMOLED 上的常驻系统界面骨架。它负责全局层级、主题令牌、导航、系统面板和覆盖层；普通页面只管理自己的控件，不直接调整全局 Z 顺序，也不直接读取 PMU。

当前实现保持 LVGL 8.3.11 与 Arduino 主循环单核访问边界，不引入实时模糊、全屏 Alpha 动画或无限增长容器。

## 2. 固定层级

从后到前固定为：

1. `app_host_`：锁屏、桌面、设置和一瞥页面。
2. `status_bar_`：桌面状态栏。
3. `panel_host_`：控制中心和通知中心共用的下拉面板。
4. `overlay_host_`：充电、闹钟、错误、OTA、关机等系统覆盖层。

所有宿主均由 `UiShell` 创建。页面创建时直接选择正确宿主作为父对象，避免依赖创建顺序碰运气维持层级。

## 3. 导航与页面生命周期

- `NavigationController` 使用固定深度 6 的栈，不分配堆内存。
- 初始路由是 `Lock`；打开桌面重置为 `Lock -> Home`；桌面返回进入锁屏。
- `Screen` 统一定义 `create/show/hide/refresh`；`UiShell` 的路由回调负责把导航栈变化映射到真实页面。
- `GlanceScreen` 持有四张息屏图的轮换索引；黑屏唤醒只恢复当前图。
- `LockScreen` 绑定现有时间、日期和星期控件，并增加电池/连接、下一闹钟摘要。
- `HomeScreen` 从 `AppRegistry` 读取描述，按 3 列 × 2 行分页；当前图标是可替换的 LVGL Symbol 占位。
- 桌面已登记时钟、活动、天气、音乐、录音、文件、主题、设置、诊断。设置进入真实页面；其他入口进入统一 `AppShellScreen` 占位页，并可用 BOOT 返回。

## 4. 主题与组件

- `UiTokens` 保存 RGB565 色值、圆角、安全边距和 48px 最小触摸尺寸，不依赖 LVGL。
- `UiTheme` 提供流萤默认主题、SAM 警报主题和壁纸一次性采样。
- 壁纸采样结果使用 Preferences 键 `theme_v1` 缓存，页面显示不重复扫描全屏像素。
- `UiComponents` 集中创建页面、卡片、主按钮、标题并统一滑杆/开关样式。
- 卡片与桌面图标默认无阴影；主按钮高度至少 56px。

## 5. 状态刷新

PMU 数据先转换为 `BatteryState` 并写入 `ui_state_store`。控制中心、锁屏和 Shell 只接收 `SystemState` 快照与 revision；相同 revision 不重复执行 Shell 刷新。

控制中心额外接收音量与亮度值，以 revision 和本地控件值共同去重，但不直接调用 PMU。控制中心与通知中心是面板中的同级页面；通知中心最多渲染 3 条 `NotificationSummary`，支持空状态和本地清空。

控制中心的 BLE/Wi-Fi 快捷项在本阶段只维护可切换的 UI 状态；省电项调整自动息屏时间，锁屏项接入真实 Shell 路由。无线连接能力分别留给计划 5 和计划 6。

系统面板的全部后代在初始化完成后显式启用 `LV_OBJ_FLAG_EVENT_BUBBLE`，由父面板统一接收 pressed、pressing、released 和 press-lost。纯 C++ `PanelGestureArbiter` 使用 16px 门槛区分纵向上滑与横向控件操作；上滑接管后会阻止按钮点击，并恢复门槛形成前可能改变的音量持久化值与亮度硬件状态。下拉打开和上滑关闭使用独立回调，所有 LVGL 查询、恢复和动画仍只发生在 UI 主循环。

## 6. 覆盖层优先级

`SystemOverlayHost` 为每个优先级保留一个槽位，并始终显示最高优先级：

| 优先级 | 用途 |
|---:|---|
| 5 | OTA、关机 |
| 4 | 闹钟、极低电量 |
| 3 | 授权、错误 |
| 2 | 充电、通知 |
| 1 | 普通弹窗 |

低优先级不能盖住高优先级。若充电提示显示期间闹钟触发，闹钟关闭后会恢复尚未关闭的充电提示。

## 7. 圆角屏与性能约束

- 设计安全区为左右 24px，重要操作按更保守的 28px 侧边距布置。
- 右上、右下和底部不放置贴边文字或关键图形。
- 面板动画只移动一个不透明父容器，时长 180ms。
- 全屏 RGB565 每张 411,640B；不增加全屏 Alpha 缓冲。
- 导航、应用注册、通知可见列表和覆盖层槽位全部有上限。
- 隐藏页面不创建独立刷新定时器；系统继续复用 1 秒状态刷新入口。

## 8. 美术与字体替换

当前图标与空状态使用 LVGL Symbol，占位资源不会改变对象尺寸或触摸热区。正式提示词、文件名、尺寸和验收流程见 `02-美术资源规范.md`。

`collect_system_glyphs.py` 会先合并人工保留字形与源码中的 CJK 字符，稳定生成 `system_glyphs.txt`；随后 `build_fonts.ps1` 生成 18/22/24px、4bpp 子集。脚本不会自动下载字体，必须传入允许固件嵌入的 TTF/OTF。

## 9. 验证状态

- HTML 预览契约：通过，包含六个 410 × 502 圆角画框与安全区。
- 当前系统面板软件回归：方向仲裁核心测试、事件接线契约和主固件构建通过；主固件 Flash 2,240,553B（47%），全局 RAM 24,192B（7%）。
- 桌面入口、导航上限、组件集中样式和覆盖层优先级均有代码契约或核心测试。
- 真机 Gate B 尚未关闭：除触摸 48px、圆角裁切、50 次设置开关内存回收、20 次锁屏转场、10 次息屏轮播和转场阻塞外，还需在控制/通知页分别从背景、卡片、按钮、滑杆和通知项完成上滑矩阵，并复核横向滑杆与轻点按钮不受影响。
