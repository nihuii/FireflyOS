FireflyOS 系统总体架构

像手机一样完整，像嵌入式系统一样克制：离线独立运行，手机连接只做增强。

410 × 502 AMOLED ESP32-S3 双核 400mAh / 一天续航 LVGL 8 单核 UI 流萤日常 × 萨姆守护

⑥ 应用层

时钟、日历、活动、天气、音乐、录音、文件、工具、设置与诊断；按需创建和回收。

⑤ 系统 UI Shell

息屏、锁屏、桌面、状态栏、控制中心、通知中心、导航栈和高优先级覆盖层。

④ 体验基础层

流萤/SAM 主题、中文字体、组件库、圆角安全区、动效令牌与资源生命周期。

③ 系统服务层

时间、闹钟、电源、IMU、音频、存储、连接、通知、天气、OTA 和诊断服务。

② 系统核心层

生命周期、静态应用注册、事件总线、状态快照、能力注册与资源治理。

① 硬件抽象层

显示、触摸、按键、RTC、PMU、IMU、ES8311、SD、Wi-Fi、BLE 与 NVS。

Android 伴侣应用

通知同步、天气、远程配置、媒体控制、找设备、配网和 OTA。

⇄ BLE

BLE 是低功耗常规通道；Wi-Fi 只在 OTA、天气直连或大文件传输时按需开启。

⇄ Wi-Fi

手机断连后，时间、闹钟、活动、本地媒体与系统设置仍独立工作。

输入触摸、按键、RTC、PMU、IMU、手机消息
后台服务读取硬件、更新模型，不直接调用 LVGL
事件与状态有界事件队列 + 最新状态快照
UI Core统一消费事件，只刷新当前可见控件
输出AMOLED、音频、存储、BLE/Wi-Fi 响应
核心设计判断： FireflyOS 在体验上采用手机式应用、系统面板与通知结构；在实现上坚持静态模块、单核 LVGL、事件驱动和按需服务。这样既能继续扩展硬件能力，也不会让 ESP32-S3 承担通用手机 OS 的进程与窗口成本。
