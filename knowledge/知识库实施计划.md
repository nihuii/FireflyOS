# 知识库更新清单

当当前主程序采纳一项设计时，按以下顺序维护知识库：

1. 用 `rg` 确认当前源码、测试和文档的真实路径。
2. 更新对应模块卡片的“当前 main”状态和参考路径。
3. 只记录最终采用的边界、最小实现和已验证风险。
4. 删除已失效的历史叙述，不追加提交流水账或构建日志。
5. 运行 `python knowledge/validate_knowledge.py`。
6. 对照 `git diff -- knowledge`，确认没有带入密钥、绝对路径或无关文件。

若功能尚未进入当前 main，继续标为历史思路参考；若真机项目未执行，不得因编译或自动测试通过而升级结论。
